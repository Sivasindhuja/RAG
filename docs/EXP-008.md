## 1. Objective

Investigate why retrieved 4.2 definition content for Q12 is not selected, and test one general, document-grounded selection/ranking hypothesis.

**Q12:** “How are international satellite communication services defined?”  
**Expected:** International communications include PSTN, GMPCS, Value Added Services, Programme Exchange, where one end of the link terminates in a foreign country; the Maritime Mobile Satellite Service and the Aeronautical Mobile Satellite Service may be treated as international communications.

**Required elements:** PSTN; GMPCS; Value Added Services; Programme Exchange; foreign-country origination/termination; MMSS treatment; AMSS treatment.

## 2. Diagnosis (exact selection/ranking failure)

- **Retrieval (frozen, unchanged):** Recall@5 1.0, Precision@5 0.4, MRR@5 1.0. Evidence `EXP001-Q12-E01` (p13, offsets **30425–31507**, clause 4.2) covered by rank 1 and rank 2 chunks.
  - Rank 1: `satcom-ngp::page_13::chunk_1::off30978` (4.3, 30978–31978, dist 0.7149, overlap 529)
  - Rank 2: `satcom-ngp::page_13::chunk_0::off30178` (4.1, 30178–31178, dist 0.7590, overlap 753)
- **Ground-truth definition content present in retrieved chunks:**
  - Chunk 1, local 28–276 (global **31006–31254**): “The International Communications Services will include PSTN, GMPCS, Value Added Services, Programme Exchange etc., where one end of th e link terminates in a foreign country i.e., the �call� either originates or terminates  in a foreign country.”
  - Chunk 1, local 277–528 (global **31255–31506**): “The Maritime Mobile Satellite Service (MMSS) and Aeronautical Mobile Satellite Servie (AMSS) may be treated as International communications, even though there may be an element of domestic traffic, in respect for operations with foreign satellites.”
  - Chunk 0, local 828–1000 (global **31006–31178**): partial definition-start sentence including PSTN/GMPCS/Value Added Services/Programme Exchange and foreign-country link termination, truncated at chunk boundary.
- **Baseline selection (EXP-003):** supported 1/3, evidence covered by a non-definitional statement.
  - Selected: “The Satellite Communication Services could be broadly classified as” (4.1, not supported, score 4.049), “In so far as International communication is concerned the existing practice of using International Inter-Governmental Systems shall continue.” (4.2 practice, supported, score 3.751), “4.3.4 Land Mobile Satellite Services (Domestic and Coastal Waters):” (irrelevant, score 3.674).
  - **Not selected:** key definitional sentences scored **2.962** each (chunk 1 definition span, chunk 1 MMSS/AMSS span, chunk 0 partial definition span) — below top-ranked candidates.
- **Root cause:** query tokens are {communication, defined, international, satellite, services}. “defined” (high IDF weight) does not appear in the actual definition sentences; definition is expressed via policy patterns (“will include…”, “may be treated as…”, “where one end…”). Those sentences overlap query content tokens but lack the intent token/matching phrasing that would rank them above generic classification/practice headings/sentences. This is a lexical selection/ranking gap for definitional-intent questions, not a retrieval failure.

---

## 3. Hypothesis (general, document-grounded)

For questions expressing definitional intent (e.g. define/defined/definition/meaning/means/what is/what are/how is/how are/describe), candidate sentences that contain document-grounded definitional/explanatory markers (include/includes/including, means, defined as, treated as, refers to, consist of, comprises, where, i.e.) and overlap query content tokens are more likely to carry the requested definition than generic classification/practice sentences with similar token overlap. Applying a modest selection-score boost to such candidates can improve definitional evidence selection without question-specific rules.

**One variable changed:** selection/ranking only (`definition_intent_boost=True`, opt-in; default `False`).

## 6. Failures / limitations

- Boost is heuristic and keyword/pattern-based; **validated only on the current 15-question evaluation set** (BL-017). Could over-promote definitional-marker sentences in other definitional-intent questions if not well aligned with evidence (no regressions observed on 15q set).
- EXP-008 selects overlapping/partially redundant definitional text (chunk 0 truncated span plus chunk 1 full span) because both are high-ranked supported candidates; traceability is correct but presentation is not deduplicated.
- Does not address Q04 list completeness or Q10 cross-reference selection (handled separately by EXP-007/EXP-006 opt-ins); does not address retrieval misses (BL-001/BL-002).
- **Citation metadata correction (separate, 2026-11-15):** EXP-008 result artifacts preserved as executed history. Post-review audit found Q12 cited 4.2 statements were labeled with chunk-level 4.1/4.3 metadata due to fixed-char chunk metadata assignment across clause boundaries (offsets/pages/text correct). Corrected via start-governing chunk metadata + statement-governing citation resolution; production index rebuilt. See `docs/EXP-008-citation-metadata-correction.md`. Fixed-char chunks may still span clauses; citation reflects governing clause of first selected statement per chunk while offsets/pages/text remain traceability anchors.
