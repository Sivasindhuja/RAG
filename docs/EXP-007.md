# EXP-007 — Heading-introduced associated answer-unit investigation (Q04/Q12)

**Date:** 2026-11-15  
**Status:** **Rejected for promotion (EXP-003 remains default).** Partial improvement: Q04 selected answer now includes all four required classifications as one verbatim heading+list unit with correct evidence/citation traceability; Q12 required definition elements remain unselected. No non-target regressions observed on frozen 15-question set; abstention unchanged. EXP-006 kept separate (not combined).  
**Scope:** Controlled answer-unit construction/selection experiment only. No chunking, embedding, retrieval, ground-truth, question, prompt, generator, or Gemini evaluation changes.

---

## 1. Objective

Investigate whether headings and their immediately associated lists or definitions should be selected as coherent verbatim answer units to address:
- **Q04:** baseline selected heading “The user sectors can be broadly classified as:” but omitted its four classifications.
- **Q12:** baseline failed to select the actual international-services definition and associated explanatory content.

Frozen inputs: `data/satcom-ngp.pdf`, `experiments/exp001_questions.csv`, `experiments/exp001_ground_truth.json`, `experiments/unanswerable_questions.csv`, fixed-character 1000/200 chunks, `sentence-transformers/all-MiniLM-L6-v2`, dense top-5 retrieval over `chroma_db_production` / `satcom_ngp_production_fixed_char`, precomputed hits, top-k, EXP-003 sibling ratio `0.5`, answer caps/citations/abstention policy, existing metrics.

## 3. Hypothesis (general, document-grounded)

An introductory span that ends with a colon (`:`) signals an immediately associated enumeration or definition/list block in policy text. Grouping such an introductory span with contiguous following spans in the same chunk until the next numbered clause start preserves heading-introduced associated content as one coherent, verbatim answer unit, improving selection of complete lists/definitions without question-specific rules.

## 6. Failures / limitations

- **Q12 unresolved:** required definition elements remain absent from selected answer. Evidence is retrieved/covered but not selected as the answer; this is a ranking/answer-unit relevance problem not addressed by colon-intro grouping. Definition sentences in chunk 1 are not attached to a colon-intro lead-in in the selected construction.
- **Q04 completeness vs metrics:** all four classifications are present in the selected verbatim statement and traceable, but supported-statement count did not increase (heading+list became one supported statement replacing heading-only supported statement). Evaluation must consider content/coverage, not count alone.
- Minor citation-support rate delta -0.0161 (16/31 → 16/32), within pre-registered tolerance (>= -0.02) but not an improvement.
- Small 15-question set; no Gemini validation.

---

## 7. Decision

**Rejected for promotion / not adopted as default or combined candidate.** EXP-003 remains the production default; EXP-006 remains a separate accepted opt-in candidate.

Rationale: hypothesis yields a clear, traceable content improvement for Q04 (all required classifications included in a verbatim associated unit) with no observed regressions and valid offsets/citations, but fails the primary target of making Q12 include required definition elements. Accepting/promoting would add complexity without solving Q12 and without aggregate gain.
